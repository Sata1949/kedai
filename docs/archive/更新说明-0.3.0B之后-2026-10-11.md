# Kedai 更新说明（0.3.0-B 之后）

> **覆盖范围**：0.3.0-B-beta（2026-09-16）→ 0.4.2（2026-10-11）。
> **分类**：**大更新** = 新增能力或重要功能；**小更新** = 修复、优化与体验改进。
> 只收录已发布内容。

## 一、大更新

**1. 二维自定义任务流**——把「怎么干活」画成流程：画布拖拽编排（另有列表编辑），节点分严格/宽松，可封静态子图；多套 API 连接可下放到节点级，节点级另可设工具轮次、上下文、超时与重试；任务可绑定流程并留快照；流程可整体导出导入；支持对比模式；内置示范流程。

**2. 编码能力包**——任务工作台能真的干活：任务工作区 + 执行者约定文件；文件变更台账（逐文件 diff）；单文件与整任务回滚、改动导出为 patch；工作区画像；内置编码流程预设；执行层加固（取消可中止并清进程树、命令上限放宽到 1800s 且输出保头保尾、压缩保留编码工作状态）。

**3. 视觉能力包**——桌面与移动端都能「看」：桌面打通图片进模型的视觉通道、大图拆分、视觉工具、Windows 截图；移动端最低要求提到 Android 11，基于无障碍服务与桥实现截图。

**4. 文学能力包**——面向文学创作的官方能力包：双开关骨架（默认关、显式启用）；角色扮演与任务各有文学增强缺省词；按创作习惯在指定位置注入风格与素材语气。

**5. 综合导入 / 导出与附件管理**——导入面重构：一个文件可含多段内容，逐段勾选执行、失败互不影响并给回执，导出不含连接与密钥；技能/流程/插件/正则收进一个四页签面板并支持虚拟文件夹；新增全局正则库，与卡级脚本按「全局在前、卡级在后」合并。

**6. 角色扮演生成流程改造**——深度/Agent 四步化（草稿→正文→批判修改→归档与词条同步）；反思强制定点修改；禁用词改同义改写；新增词条同步两档开关；草稿默认折叠、档位记忆；纯文字卡回复按白名单渲染折叠块/状态块。

**7. 世界书遵循修复**——关键词只出现在开场白或角色回复里也能触发（此前只扫用户消息）；命中设定带统一说明头并置于引用边界内；面板新增「扫描窗口」独立项（原「扫描深度」实为插入深度）；漏写 `{{world_info}}` 占位符时预览给可见提示。

**8. 新手教程大修**——首启引导扩到 19/20 步，补导入角色卡、综合导入导出、附件管理、MCP 与能力包、发送失败处理；「带我去设置」可直达独立面板；教程文案与关于页同源并加防漂移门禁。

**9. 任务可靠性**——任务事件落库 + 补拉端点 + SSE 回放 + 前端按 `seq` 断点续拉，断线不丢进度；任务执行体完整、草稿可用。

**10. 插件与 MCP 治理**——插件热重载增删同步、求值器升级；MCP 协议升级到 2025-06-18 并补韧性、新增管理面。

**11. 操作电脑的安全前提**——屏幕/输入类操作风险提级，新增急停与操作审计。

**12. 对外发布**——定名 **KedaiAgent**、MIT 协议、仓库转公开并发布首个正式版；产品定性为**通用 LLM 智能体 harness**，角色扮演/任务工作台为平级双顶层模式，垂直能力以官方能力包交付（默认关、显式启用）。

## 二、小更新

**性能与体积**——首屏拆掉弹窗反向耦合不再预载；渲染缓存有界化 + 虚拟滚动条数窗口；新增前端体积预算门禁；角色表加派生列提速约 3~3.8×；`cargo test` 并发上限 2 → 8。

**正确性修复**——发送失败可见（错误条 + 重试 + 停止中过渡态 + 失败保留草稿）；酒馆预设导入判定修复（自 0.2.0 起部分预设导不进）；复杂模式空楼层不再注入空白；默认提示词与文学包/工具段三处冲突对齐；Android 命令执行桥双层缺陷修复（`bash` 恢复可用）；乱弹 cmd 窗口修复。

**体验与界面**——界面观感与动效三轮收口（骨架屏、过渡节奏、连接卡片、设置左导航等）；消息排版四修；悬浮窗移植（沙箱新增楼层控制接口）。

**接口与兼容**——接口三方言（OpenAI / Responses / Anthropic）并自动剥离 Base URL 端点后缀；依赖安全升级；前端修复线 12 项清零、注释质量审计。

**版本说明**——0.4.1 发布当日曾撤回（发送/生成失败无可见反馈），修复后按裁定不升版本、仍以 0.4.1 重发（即上面的「发送失败可见」）；当前版本 **0.4.2**。
