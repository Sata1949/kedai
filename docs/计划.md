**ID 纪律**:ID **沿用源文档编号**(`P-8`、`批次 5`、`4.5`、`L16`、`T1`、`D.3`、`B.4b` 等),
**不得重编号**——仓库存在跨文档按编号引用。新增条目应先向源文档编号体系靠拢。

**状态口径**:`未启动` = 代码中查不到任何落地痕迹;`进行中` = 部分改动已提交但批次未收口;
`部分完成` = 批次内部分项已落地并验证,余项未做(须注明已完成部分)。

**验证口径(2026-10-06 起)**:批次收口一律以**真实模型实测**为准(口径与流程见 `../AGENTS.md`
「真实模型实测」节);「状态」段收口时须写实测结论与证据路径,mock 测试结果不构成收口依据。

**裁定依据的核对方法**:凡标注实测结论处,均为 2026-09-16 在本仓库执行
`grep` / `Read` / `node tools/count-tests.mjs --check` / `npm run lint -w web` 等命令得到,
