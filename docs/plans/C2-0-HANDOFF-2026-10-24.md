## 四、行为/兼容性变化

1. **设置非法值从「200 + 忽略」变为「400 + 点名字段」**。外部客户端如果依赖旧的静默行为，会看到 400；前端设置页当前发送的值均在合法区间内。错误文案示例：`default_top_p 必须在 0.0..=1.0`。
2. **`loadTaskDetail` 返回 `boolean`**。现有事件/调用方忽略返回值，不受影响；新代码可据此处理失败。
3. **`selectTask` 失败回退**。详情 500/网络失败时，UI 回到上一个任务，而不是显示旧详情配新 id；旧的 calls/changes 会补拉。
4. **`deleted` 事件清理持久化选择**。任务被删除后刷新页面不会残留悬空 `currentTaskId`。
5. **门禁更严**：新增 `v-model`/`.value =`/动态 `import()` 检测；新直写若确有理由，必须在上行写 `arch-allow: 理由`（或文件头 `arch-allow-file: 理由`），否则 FAIL。
6. **画布懒加载入口路径变化**：`utils/flowCanvasChunk` → `components/settings/flowCanvasChunk`；外部无公共 API 依赖，仅两处内部 import/mock。
7. **`start.ps1` 尊重 `PORT`/`.env`**：以前用户设 `PORT=30xx` 时脚本仍检查/打开 3001，现在与服务端/launcher 一致。
